Privacy Policy for PadMute

Last Updated: October 25, 2026

AltTab Technologies LLC (“we,” “our,” or “us”) respects your privacy. This Privacy Policy describes how PadMute - Mute Mic with Keyboard & Gamepad (the “Application”) handles information on your Windows device.

1. Data Collection and Local Architecture

PadMute is built with a strictly Local-First architecture:

  • Personal Data: We do not collect, store, or transmit any personally identifiable information (PII).
  • Usage Analytics: We do not track how you use the Application. There are no telemetry, tracking cookies, advertising software, crash-reporting, or background reporting services embedded in the Application.
  • Network Access: The Application operates entirely on your local machine and does not transmit telemetry or user settings over the internet. The only online activity is the Microsoft Store license and purchase check described in Section 3, which Windows performs.

2. Information Handled Locally on Your Device

To provide its core functionality, the Application interacts with system resources locally:

  • Microphones: The Application uses Windows audio APIs to mute and unmute your microphones, to read whether they are muted, and to check whether an app is currently using a microphone (for the optional overlay display mode). It never records, listens to, or stores audio.
  • Keyboard Shortcut: The Application registers one global keyboard shortcut with Windows (by default Ctrl+Shift+M). It does not record or log what you type.
  • Game Controller Input: The Application reads the button state of connected game controllers so it can detect your controller shortcut. This input is evaluated in memory, is never saved or transmitted, and the Application only acts on the shortcut you configured.
  • Configuration Settings: Your preferences (e.g., shortcuts, overlay position and display mode, theme) are stored locally on your device in the Application's local settings.

3. In-App Purchases and Microsoft Store Services

The Application uses official Microsoft Store APIs to check license status and process the optional PadMute Pro one-time upgrade:

  • All payment transactions, billing details, and license verification are handled directly and securely by Microsoft under the Microsoft Privacy Statement.
  • AltTab Technologies LLC never processes, handles, or stores your credit card, payment details, or Microsoft Account login credentials.

4. Permissions

The Application is a desktop app that runs with your normal user rights. It is declared as “full trust” so that it can use global shortcuts, read game controllers, and show a tray icon and an on-screen overlay, and it declares the microphone capability because it controls the mute state of your microphones. It does not access your files, contacts, camera, or location.

5. Third-Party Services

The Application does not integrate with any third-party advertising networks, analytical services, or social media SDKs.

6. Children

The Application does not collect information from anyone, including children.

7. Changes to This Privacy Policy

We may update this Privacy Policy from time to time to reflect future software enhancements or operational updates. Any changes will be indicated by the “Last Updated” date at the top of this policy page.
